# ♻️ Smart Waste Sorting System

AI-based waste sorting system using computer vision deployed on NVIDIA Jetson Nano, integrated with Arduino-controlled actuation for automated classification.

---

## 📌 Overview

This project presents an intelligent waste sorting system that combines computer vision and embedded systems to automate the classification of waste materials.

The system captures images using a camera connected to a Jetson Nano, processes them through an AI-based classification model, and sends control signals to an Arduino system that actuates a mechanical sorting mechanism.

---

## ⚙️ System Architecture

* Image acquisition using camera module (Jetson Nano)
* Image processing and classification (Python + OpenCV + API)
* Decision-making based on classification output
* Communication with Arduino for actuation
* Mechanical sorting system (belts, pulleys, or compartments)
